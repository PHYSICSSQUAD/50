# 🔥 Flare 3D — تجربة ثلاثية الأبعاد تفاعلية

تجربة WebGL تفاعلية بالعربية (Three.js) بيت أجملها بالكامل في ملفات HTML مستقلة:
شعلة خشبية بتسقط من السما، نار مخيّمة واقعية، شعار المجموعة بألعاب نارية،
وبرج شعلة صناعية (Flare Stack) بلهب ودخان.

> كل ملف مكتفي بذاته (Self-contained) — الـ Three.js والشعار مدمجين جوا الملف،
> من غير أي اعتماد على شبكة خارجية وقت التشغيل.

---

## 🚀 التشغيل محليًا

### الطريقة الأسهل (من غير أي أدوات)
نزّل `index.html` وافتحه مباشرة في المتصفح. 🎉

### أو بسيرفر محلي (أقرب للبيئة الحقيقية)
```bash
npm install   # مرة واحدة بس
npm start     # هيشغّل سيرفر على http://localhost:3000
```

## ☁️ النشر على Vercel

### الطريقة الأسرع (من غير Git)
1. ارفع مجلد المشروع إجمال كده على [vercel.com/new](https://vercel.com/new)
2. الإطار بيتمد تلقائيًا (Static Site) — مفيش إعدادات مطلوبة
3. دوس Deploy ✅

### الطريقة المفضلة (GitHub + Vercel)
```bash
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/USERNAME/flare-3d.git
git push -u origin main
```
بعدها اعمل [Import للمستودع في Vercel](https://vercel.com/new) وهينشر تلقائيًا
مع كل `git push` جديد (Continuous Deployment).

| المسار | الصفحة |
|---|---|
| `/` | الشعلة → النار → الشعار + الألعاب النارية |
| `/industrial-flare.html` | برج الشعلة الصناعية (لهب حي + دخان) |

## 🎮 أسلوب اللعب (التجربة الرئيسية)

| الزر | الوظيفة |
|---|---|
| `SPACE` | تقدّم المراحل: سقوط الشعلة ← النار ← الشعار + ألعاب نارية ← إعادة |
| `F` | ملء الشاشة / خروج |
| كليك / لمس | نفس فعل SPACE |

### تسلسل الأحداث
1. **SPACE (1)** — الشعلة الخشبية تنزل من أعلى الشاشة، ترتد من أسفلها، وتختفي
2. **SPACE (2)** — نار مخيّمة واقعية بتتّولد تدريجيًا على كومة حطب
   (لسان لهب مضطربة، جمر، دخان، انعكاس متوهج على الأرض)
3. **SPACE (3)** — النار بتختفي ويظهر **شعار المجموعة** بألعاب نارية متزامنة
4. **SPACE (4)** — العودة للبداية

---

## 🧱 التقنيات

- **Three.js r128** (مدمج بالكامل)
- **WebGL shaders** مكتوبة يدويًا: لهب مضطرب، سما متدرجة، توهجات
- **فيزياء مخصصة**: جاذبية، ارتداد (restitution)، ضغط/تمدد (squash & stretch)،
  اهتزاز كاميرا، جزيئات (جمر/شرر/دخان/ألعاب نارية)
